## `validate_files()` vs `test_validation_program_files()` 비교 분석

### 📋 **전체 구조 비교**

| 항목 | `validate_files()` (현재) | `test_validation_program_files()` (신규) |
|------|---------------------------|------------------------------------------|
| **검증 단계** | 4단계 | 6단계 |
| **반환 형태** | `Tuple[bool, List[str], List[str], List[str]]` | `Dict` (구조화된 결과) |
| **검증 순서** | 단순 순차 | 의존성 기반 순차 |
| **에러 처리** | 간단한 수집 | 단계별 상세 추적 |

---

### 🔍 **단계별 상세 비교**

#### **Step 0: 파일 객체 준비**
- **현재**: 없음 (FastAPI가 자동으로 UploadFile 제공)
- **신규**: `file_path_to_upload_file()` - 테스트용 변환 로직

#### **Step 1: 파일 타입 검증**
- **현재**: 없음 (암묵적으로 파일 읽기 시 확인)
- **신규**: 
  - `validate_ladder_zip_file_type()`
  - `validate_template_file_type()`
  - `validate_comment_file_type()`
  - **환경변수 기반** 확장자 체크

**병합 방안**: 현재 코드에 타입 검증을 **최우선 단계**로 추가

---

#### **Step 2: ZIP 파일 구조 검증**

**현재 (`_validate_zip_file`)**:
```python
- zipfile.is_zipfile() 체크
- 파일 목록 추출 (namelist)
- 빈 ZIP 체크
```

**신규 (`validate_ladder_zip_structure`)**:
```python
- zipfile.testzip() 체크 (무결성)
- __MACOSX 필터링
- 확장자 제거한 파일명 리스트 반환
- 구조화된 딕셔너리 반환 (file_list, file_count)
```

**차이점**:
- 신규는 **무결성 체크** 추가 (`testzip()`)
- 신규는 **맥OS 시스템 파일 제외**
- 신규는 **확장자 제거** 후 파일명만 추출

**병합 방안**: 
1. `testzip()` 추가로 무결성 검증 강화
2. `__MACOSX` 필터링 추가
3. 반환값을 딕셔너리로 변경

---

#### **Step 3: XLSX (템플릿) 파일 구조 검증**

**현재 (`_validate_xlsx_file`)**:
```python
- 하드코딩된 컬럼명 체크: ["로직파일명", "분류", "템플릿명"]
- "로직파일명" 컬럼 추출
- NaN 제거
```

**신규 (`validate_template_file_structure`)**:
```python
- 환경변수 기반 필수 컬럼 체크
- "Logic ID" 컬럼 추출
- 중복 Logic ID 체크 ⭐
- 구조화된 딕셔너리 반환 (logic_ids, row_count)
```

**차이점**:
- 신규는 **환경변수로 컬럼명 관리** (유연성)
- 신규는 **중복 체크** 로직 추가
- 컬럼명이 다름: `로직파일명` vs `Logic ID`

**병합 방안**:
1. 환경변수 기반으로 변경 (설정 분리)
2. 중복 체크 로직 추가 ⭐
3. 컬럼명 통일 필요

---

#### **Step 4: CSV (커멘트) 파일 구조 검증**

**현재 (`_validate_csv_file`)**:
```python
- 하드코딩된 컬럼명 체크: ["파일명", "디바이스명", "설명"]
- 인코딩 자동 감지 (utf-8 → cp949 → latin-1)
```

**신규 (`validate_csv_structure_from_bytes`)**:
```python
- 환경변수 기반 컬럼명 체크
- 환경변수 기반 인코딩
- csv.reader 사용 (더 저수준)
- 헤더 행 인덱스 지정 가능
```

**차이점**:
- 신규는 **환경변수로 인코딩 관리**
- 신규는 **헤더 행 위치 지정 가능** (유연성)
- 현재는 pandas, 신규는 csv.reader

**병합 방안**:
1. 환경변수 기반으로 변경
2. 헤더 행 인덱스 옵션 추가
3. pandas를 유지하되 환경변수 인코딩 적용

---

#### **Step 5: 파일 교차 검증**

**현재 (`_validate_file_cross_reference`)**:
```python
- ZIP 파일 목록 vs XLSX 로직파일명
- 경로 구분자 통일 (\\ → /)
- 파일명만 일치하는 경우도 허용
- 누락 파일 최대 10개만 표시
```

**신규 (`validate_ladder_files_match`)**:
```python
- 집합 연산 사용 (교집합, 차집합)
- matched_files (교집합)
- missing_files (필수-실제)
- extra_files (실제-필수) ⭐
- 누락 파일에만 집중
```

**차이점**:
- 신규는 **집합 연산**으로 더 간결
- 신규는 **불필요한 파일**도 추적
- 신규는 **matched_files를 반환**하여 다음 단계 연결

**병합 방안**:
1. 집합 연산 방식 채택 (더 효율적)
2. extra_files 로깅 추가 (정보성)
3. matched_files 반환으로 다음 단계 준비

---

#### **Step 6: 매칭된 레더 CSV 파일들 구조 검증** ⭐ (신규)

**현재**: 없음

**신규 (`validate_matched_ladder_csv_structures_in_memory`)**:
```python
- ZIP 내부의 매칭된 CSV 파일만 검증
- 각 CSV의 필수 컬럼 체크
- 실패한 파일 목록 수집
- __MACOSX 필터링
```

**병합 방안**: 
- **새로운 단계로 추가** (현재 코드에 없는 검증)
- XLSX/CSV만 검증하고 ZIP 내부 CSV는 검증 안 하던 문제 해결
