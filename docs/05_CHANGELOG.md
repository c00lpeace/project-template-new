## 2025-01-18 - 프로그램 검증 로직 개선

### 수정된 파일
- ✅ `ai_backend/src/api/services/program_validator.py`

### 번합 1단계 적용 내용

#### 1. 파일 타입 사전 검증 추가 (Step 0)
- **기능**: 파일 확장자 체크를 통한 조기 검증
- **검증 항목**:
  - 레더 ZIP 파일: `.zip`, `.7z` 확장자
  - 분류체계 XLSX 파일: `.xlsx`, `.xls` 확장자
  - 커멘트 CSV 파일: `.csv` 확장자
- **효과**: 잘못된 파일 타입을 즉시 차단하여 불필요한 처리 방지

#### 2. ZIP 파일 무결성 검증 추가
- **기능**: `zipfile.testzip()` 메서드를 통한 CRC 체크섬 검증
- **효과**: 손상된 ZIP 파일을 업로드 전에 감지
- **에러 메시지**: "손상된 파일: [filename]"

#### 3. 시스템 파일 필터링 추가
- **기능**: ZIP 내부의 시스템 파일 자동 제외
- **필터링 대상**:
  - 디렉토리 엔트리 (`/`로 끝나는 항목)
  - macOS 메타데이터 (`__MACOSX`)
  - macOS 설정 파일 (`.DS_Store`)
  - 숨김 파일 (`.`으로 시작)
- **경고 메시지**: "시스템 파일 {count}개 제외됨 (전체: X개 → 유효: Y개)"

#### 4. 중복 Logic ID 검사 추가
- **기능**: XLSX 파일의 '로직파일명' 컨럼에서 중복된 값 감지
- **구현 방법**:
  - `collections.Counter` 사용하여 효율적으로 중복 탐지
  - 중복된 항목 목록과 개수 표시
- **에러 메시지**: "중복된 항목 {count}개: [list]"
- **경고 메시지**: 중복된 각 항목의 상세 정보 (처음 5개)

### 추가 개선 사항 적용

#### 개선 1: 필터링 통계 경고
- **위치**: `_validate_zip_file()` 메서드
- **내용**: 제외된 시스템 파일 개수와 전/후 파일 수 표시
- **목적**: 사용자에게 투명성 제공

#### 개선 2: 중복 상세 정보 경고
- **위치**: `_validate_xlsx_file()` 메서드
- **내용**: 각 중복된 Logic ID의 중복 횟수 표시
- **표시 방식**: "  '[filename]' 파일명이 X번 중복됨"
- **제한**: 처음 5개만 표시하여 과도한 로그 방지

### 기술적 세부사항

#### 반환 형태 유지
- **기존**: `Tuple[bool, List[str], List[str], List[str]]`
- **변경 후**: 동일 (100% 하위 호환성 유지)

#### 에러 처리 패턴 유지
- `errors.append()` 방식 유지
- `warnings.append()` 방식 유지
- 조기 종료 패턴 유지
- try-except 구조 유지

#### 성능 영향
- **파일 타입 검증**: 초기 차단으로 오히려 성능 향상
- **testzip()**: ZIP 크기에 비례하여 추가 시간 소요 (일반적으로 1초 이내)
- **필터링**: 리스트 컴프리헨션으로 O(n) 복잡도
- **중복 검사**: Counter 사용으로 O(n) 복잡도

### 기대 효과

1. **사용자 경험 향상**
   - 잘못된 파일을 즐시 감지하여 빠른 피드백
   - 명확한 에러 메시지로 문제 해결 용이

2. **데이터 무결성 향상**
   - 중복 Logic ID 사전 차단
   - 손상된 ZIP 파일 차단
   - 불필요한 시스템 파일 제거

3. **비용 절감**
   - S3 업로드 전에 문제 감지
   - 불필요한 후속 처리 방지

4. **크로스 플랫폼 호환성**
   - macOS 시스템 파일 자동 처리
   - Windows/Linux 환경에서도 정상 동작

### 테스트 권장 사항

```python
- 잘못된 확장자 파일 (.txt, .doc 등)

# 2. ZIP 무결성
- 정상 ZIP 파일
- 손상된 ZIP 파일

# 3. 시스템 파일 필터링
- macOS에서 압축한 ZIP
- Windows에서 압축한 ZIP

# 4. 중복 검사
- 중복 없는 XLSX
- 중복 있는 XLSX (2개, 10개 이상)
- NaN 값 포함 XLSX
```
